# Persona Calendar
A Calendar for persona games to help you plan and experience as much of the game as possible with as little spoilers as possible.

## Features
- Displays weather, schedule availability, and events.
- Displays available confidants, special confidant activities, and confidant events.
- Displays jobs, limited activities, and special sales.  
- Spoiler option for more detailed events.

## Recommendation, suggestions, corrections
I'd love recommendations/suggestions, so please consider opening an issue if you have any, whether they are code or content related. For content corrections, the google sheet for the calendar is open, you can add a comment there and open an issue.
