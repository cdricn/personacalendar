# Persona Calendar
A calendar website for the persona games, showing the weather, confidant availability, and events to help you plan your gameplay.

## Recommendation, suggestions, corrections
I would love recommendations/suggestions, so please consider opening an issue if you have any, whether they are code or content related. For content corrections, the google sheet for the calendar is open, you can add a comment there and open an issue.
